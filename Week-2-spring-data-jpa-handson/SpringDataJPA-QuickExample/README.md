ORM Learn - Spring Boot & MySQL Integration

This repository demonstrates the foundational setup of a Spring Boot application integrated with a local MySQL database using Spring Data JPA and Hibernate.

 Accomplishments:
* **Database Installation:** Successfully installed and configured a localized MySQL 8.0 instance running on port `3306`.
* **Schema Definition:** Created a dedicated database schema named `ormlearn` inside the MySQL server environment.
* **IntelliJ Data Source Link:** Resolved driver dependencies and established a verified, live connection between the IDE database tools and the active server instance.
* **Properties Configuration:** Successfully mapped application data sources using matching connection parameters (`root` credentials) inside `application.properties`.
* **Verified Handshake:** Executed the core application, achieving a verified Hibernate persistence unit initialization and Hikari connection pool startup without active runtime errors.
