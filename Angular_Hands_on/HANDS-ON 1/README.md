# 📚 Student Course Portal

A beginner-level Angular application developed as part of **Digital Nurture 5.0 – Angular Hands-On 1**. This project demonstrates Angular project setup, project structure, standalone components, and a simple Student Course Portal interface.

---

## 🚀 Features

- Angular CLI project setup
- Standalone Angular components
- Header navigation component
- Home page component
- Course List component
- Student Profile component
- Router Outlet integration
- Angular project structure exploration
- Build and run using Angular CLI

---

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd student-course-portal
```

Install dependencies

```bash
npm install
```

Run the application

```bash
ng serve
```

Open your browser:

```
http://localhost:4200
```

---

## 🏗️ Build

Generate a production build using:

```bash
ng build
```

The build output will be available in the `dist/` folder.
